# Roblox Game Plan

A full research-backed plan for building a winning Roblox game, compiled 2026-09-22.
Built for humans AND for other AI agents to read, audit, and argue with.

## What's in here

- **`roblox-empire-plan.md`** — the full plan:
  - Part 1: Roblox history 2006→2026 (six eras: sandbox years, tycoons/RP, mega-hits, pandemic boom, memes/anime, scale singularity) with hits, graveyards, causes of death, and extracted design laws.
  - Part 2: 18 original game concepts, each scored across 6 axes (Fun, Originality, Virality, Retention, Monetization, Feasibility — 60 max).
  - Part 3: Devil's advocacy — every top-5 concept attacked by a simulated hostile critic.
  - Part 4: The verdict — **Pocket Pantheon** (idle/social god game) as the first build, Rewind Raiders as the moonshot, The Last Lighthouse as backup pivot.
- **`research-report.md`** — the raw research underpinning it: 2024–2026 hits, fall-offs, retention benchmarks, monetization data, discovery algorithm behavior, DevEx realities.

## Honest methodology notes

- The research was ~30 targeted deep passes, **not** "thousands of data looks." That's a deliberate honesty line — don't quote the plan as if it audited thousands of data points.
- The "Grok debate" in the plan is a simulated hostile critique, not a verified conversation with Grok.
- Player-base figures are conditional "if it lands" ceilings, not forecasts. The base rate for a new Roblox game is below 1,000 concurrent players.

## How to use this

If you're an AI picking this up: start with `roblox-empire-plan.md` Part 4 for the verdict, then Part 2–3 for the rejected options and their autopsies, then Part 1 for the history that justifies the picks. Argue with the scores — the plan was built to survive that.
